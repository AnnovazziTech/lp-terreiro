# Templo de Umbanda Guardião da Luz

Landing page institucional desenvolvida para o Templo de Umbanda Guardião da Luz, localizado em São José do Rio Preto - SP.

## Sobre o Projeto

Esta landing page foi desenvolvida para apresentar de forma completa e acessível todas as informações sobre o terreiro, seus fundamentos, teologia e funcionamento. O design segue uma estética minimalista e espiritual, com cores que remetem à tradição umbandista.

## Estrutura do Projeto

```
LP TERREIRO/
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos da página
├── js/
│   └── main.js         # Scripts de interatividade
├── img/
│   └── ...             # Imagens do site
└── README.md           # Este arquivo
```

A página é totalmente responsiva e adaptada para:
